## Commands
```sh
RELEASE=1 npm run build && npm run test:pdf && npm run e2e && npm run a11y && RELEASE=1 npm run check:copy
gh pr create --base main --head claude/intelligent-sagan-poq45q --title "Commit History v1" --body-file <file>
gh run list --branch main --limit 3 --json workflowName,conclusion,url
SITE_URL=$(npx tsx --eval "import('./src/content/site.ts').then(m => console.log(m.SITE_URL))")
BASE_URL="$SITE_URL" npx playwright test --grep @smoke --project=desktop
curl -sSf "$SITE_URL/resume.pdf" -o /tmp/prod.pdf && pdfinfo /tmp/prod.pdf | awk '/^Pages:/{print $2}'
curl -sI "$SITE_URL/" | grep -iE '^(content-security-policy|x-robots-tag)'
git tag v1.0.0 <main merge sha> && git push origin v1.0.0
```

## Acceptance
- A1. Release build clean. Proof: the pre-flight line. Threshold: all exit 0.
- A2. Production deploy green. Proof: `gh run list --branch main`. Threshold: `ci` and `deploy` succeed on the merge commit.
- A3. Production smoke. Proof: `BASE_URL=$SITE_URL ... --grep @smoke`. Threshold: pass (museum mode with `?test=1`, CSP present, no violations).
- A4. Production PDF is one page. Proof: `pdfinfo`. Threshold: `1`.
- A5. Production is indexable. Proof: `curl -sI`. Threshold: CSP present, no `x-robots-tag`.
- A6. Tag. Proof: `git ls-remote --tags origin v1.0.0`. Threshold: points at the `main` merge commit.
