# WP-32: Cross-browser and resilience

## Goal
The site holds up beyond headless Chromium: Firefox and WebKit run the DOM, classic and no-WebGL specs in CI (non-blocking smoke), the museum survives 20 full loops through every stop with zero page errors, and Emeka has a 10-step checklist to run on his own phone, including the 3-minute frame-rate check, before release.

## Notes
- Real iOS Safari behavior (address bar, background tabs, Low Power Mode) is only verifiable on a device; the checklist covers it.
- The 20-loop spec is the guard against context churn and leaks; it is slow, so keep it out of `@smoke`.
- Firefox exposes the WebGL renderer through `gl.RENDERER`; boot uses it as the fallback, which the DOM specs indirectly cover.
