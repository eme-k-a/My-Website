# WP-12: Verafin exhibit

## Goal
Exhibit No. 01, "The Reporting Engine", replaces the placeholder in the Verafin case: one sculptural object built only from code primitives and shared materials (a frosted column feeding a six-by-six bar grid, three brass plugin cartridges docked in it) with one slow motion (the report refresh), inside the 0.65 m slot, under 20k triangles, in its own lazy chunk of at most 40 KB gzip. It sets the style bar that every later exhibit is calibrated against at gate G2.

R5 Exhibit Builder A. R2 Art Director signs the concept checklist.

## Forbidden

## Notes
- The cut ideas stay cut: no 150-sphere stream, no hover cartridge, no amber "fraud" bar (backlog only, EXPERIENCE §12).
- Restraint reads as craft. Spend detail only where it reads at 3 m; the triangle estimate is about 2,500.
- Use one `InstancedMesh` for the 36 bars and update instance matrices only during the 1.6 s ease; outside it, nothing changes, so `FrameDriver` can stop rendering when idle.
- Materials: `walnut`, `frostedGlass`, `accentGlow`, `brass`, `ceramic` only. A per-exhibit emissive change uses `useMaterialInstance`, which shares the compiled program.
- Deterministic: all randomness from `rng(seed)`; `?test=1` must render the reduced-motion pose every frame, or the visual baselines flake.
