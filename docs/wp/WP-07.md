# WP-07: Test harness

## Goal
Playwright 1.56.1 runs against the built site served with production headers, on the preinstalled Chromium with SwiftShader WebGL, in four projects (desktop, Pixel 7, Pixel 7 landscape, no-WebGL). A global fixture fails any test on console errors, page errors, CSP violations, requests to other origins or troika fallback-font requests. Shared helpers (`waitForMuseum`, `goToStop`, `shot` and input helpers) and the reusable exhibit acceptance spec exist for every later WP. A glyph-coverage check proves every 3D string exists in the `.woff` font troika will use.

## Notes
- troika's default font is fetched from a CDN, and missing glyphs make it fetch fallback fonts from jsDelivr. The cross-origin guard and the `/fonts/unicode-fallback/` guard turn both into test failures; the glyph check catches them before any browser runs.
- troika cannot read `.woff2`; the glyph check must load the same `.woff` the kit passes to `<Text font>`. WP-28 switches both to subset files.
- SwiftShader output differs by CPU, so screenshot comparison is CI-only; locally `@visual` specs skip unless `VISUAL_LOCAL=1`.
- `ready` (ARCHITECTURE §13.4) waits for Suspense, troika sync, `compileAsync` and two frames. Never replace it with fixed sleeps.
- The CSP-violation case in `guards.spec.ts` must be produced in the page, not by Playwright's own `addScriptTag` bypass.
- Parallel worktrees must use their own `PORT` (`4173 + N`); `reuseExistingServer` is off in CI.
- Pixel 7 emulation sets `hasTouch` and `isMobile`; the CDP flick helper must target the page, not the canvas, since sections own scrolling.
- R0 ruling (2026-10-15): `threeDStrings(c, now?)` returns `{ kind, text, font, for }` objects. `check-glyphs` reads `.text` and `.font` and passes the build date.
