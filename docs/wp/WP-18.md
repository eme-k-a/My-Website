# WP-18: Preview deploy

## Goal
Every green CI run on a branch or pull request deploys the tested `dist/` to a Netlify preview URL (an alias per branch or PR, `noindex`), and `main` deploys to production. The site lives on a free `*.netlify.app` subdomain whose URL is the single `SITE_URL` value in content. A smoke test against the deployed preview proves it boots in museum mode with the production CSP.

## Forbidden
- Standard list (`docs/wp/_TEMPLATE.md`).
- Netlify Git builds, `netlify build`, or any deploy without `--no-build`; netlify-cli as a devDependency (use `npx --yes netlify-cli@27.12.1` in CI only).
- Committing tokens, site ids or any secret; echoing secrets in logs.
- Deploying from a fork's workflow run.
- Production deploys from any branch other than `main`.

## Commands
```sh
npm ci
npm run verify && npm run build
grep -o 'https://[a-z0-9-]*\.netlify\.app' dist/index.html | sort -u
python3 -c "import yaml; yaml.safe_load(open('.github/workflows/deploy.yml')); print('yaml ok')"
# after merge and push (R0):
gh run list --workflow deploy.yml --limit 1 --json conclusion,url
curl -sI "https://claude-intelligent-sagan-poq45q--<name>.netlify.app/" | grep -iE '^(content-security-policy|x-robots-tag)'
BASE_URL="https://claude-intelligent-sagan-poq45q--<name>.netlify.app" npx playwright test --grep @smoke --project=desktop
```

## Acceptance
- A1. Workflow valid. Proof: the `python3` line. Threshold: `yaml ok`.
- A2. `SITE_URL` used everywhere. Proof: the `grep -o` on `dist/index.html`. Threshold: exactly one host, the real one; `grep -c '\[placeholder: netlify' src/content/site.ts` is 0.
- A3. Deploy succeeds on the branch (R0, after push). Proof: `gh run list --workflow deploy.yml`. Threshold: latest run `success`, preview URL in its summary.
- A4. Preview boots in museum mode without CSP violations. Proof: the `BASE_URL=... npx playwright test --grep @smoke` run. Threshold: green (`data-mode="museum"` with `?test=1`, CSP header present, zero violations).
- A5. Preview is not indexable. Proof: the `curl -sI` line. Threshold: `x-robots-tag: noindex` present on the preview; absent on production later (WP-33).

## Notes
- netlify-cli 27.x builds by default; every deploy passes `--no-build`, so Netlify only serves the `dist/` CI built and tested (and never needs Chromium).
- `--alias` is limited to 37 characters.
- A preview without `noindex` can outrank production in search; append the header only on previews.
- If `NETLIFY_AUTH_TOKEN` is missing, the deploy job must fail with a clear message, not skip silently; G2 can fall back to reviewing locally served `dist/` (record that in the report).
- `SITE_URL` is the one place the domain lives; a custom domain later is a one-line change here.
