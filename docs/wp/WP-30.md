# WP-30: Accessibility

## Goal
Everything in the gallery is reachable and understandable without a mouse, without sight of the canvas and without motion: a keyboard-only walk reaches every story in catalogue order and returns focus correctly, axe finds zero violations in every DOM state, the live region speaks only when asked, and Lighthouse accessibility is at least 0.95.

## Notes
- The canvas sits under the DOM; every case has a DOM "Read the story" button, so keyboard users never need the canvas.
- Announcing every scroll arrival spams screen readers; only keyboard and HUD moves announce.
- The native `<dialog>` provides the focus trap; check that focus returns where EXPERIENCE §5.10 says, not just "somewhere".
