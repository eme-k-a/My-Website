# Someone Showed Up

KlarUp’s case holds a smoked-glass disc on a graphite foot. Each light is a completed practice session. Three missing violet marks leave room for a mint check-in to cross from the partner’s row. The exhibit clock advances the pulse through the depth of the disc. Reduced motion keeps it still.

The interactive view at [/studies/#klarup](/studies/#klarup) labels the rows and plays the missed session, check-in and return in sequence. The [story](/exhibit/klarup/) includes a still for visitors reading the static page.
