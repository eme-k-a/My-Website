# WP-31: SEO and sharing

## Goal
The site is found and shared well: a JSON-LD Person on `/` and `/resume/` (current employer only while current, no email or phone), a sitemap and robots file generated with `SITE_URL`, a favicon set and apple-touch icon, and a 1200 x 630 Open Graph image per exhibit plus home and resume, rendered from content and committed. Lighthouse SEO is at least 0.95 and every exhibit page reads fully with JavaScript off.

## Forbidden
- Standard list (`docs/wp/_TEMPLATE.md`).
- `email` or `telephone` in JSON-LD; listing the PDF in the sitemap (it is linked, not listed); brand logos in icons or OG images; a web manifest.
- Network fonts in the OG renderer (use the same `@fontsource` files).

## Acceptance
- A1. Lighthouse SEO at least 0.95 on `/`, `/resume/` and an exhibit page. Proof: `npm run lh` (advisory locally) and the CI `lighthouse` job. Threshold: at least 0.95 each.
- A2. Exhibit pages readable without JS and uniquely titled. Proof: the JS-off and OG-title tests and the `uniq -d` command. Threshold: pass; `uniq -d` prints nothing.
- A3. JSON-LD correctness. Proof: `npx vitest run --project unit src/seo`. Threshold: pass.
- A4. Sitemap and robots. Proof: `cat dist/robots.txt`, `grep -c '<loc>' dist/sitemap.xml`. Threshold: robots points at `<SITE_URL>/sitemap.xml`; 12 `<loc>` entries.
- A5. OG images. Proof: `ls public/og/ | wc -l` and `gen-og.test.ts`. Threshold: 12 PNGs plus `manifest.json`; all 1200 x 630; manifest fresh.
