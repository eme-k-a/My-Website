# Editions

The case holds a ceramic report tile on a low turntable. The front has a heading, report lines and an activity chart. A graphite core separates the ceramic faces. Three solid cartridges mount on the reverse. The ultramarine cartridge projects from the rail so its depth is visible from the side.

The exhibit clock turns the tile slowly. Reduced motion holds the front three-quarter view. In the [interactive view](/studies/#verafin), releasing the blue module removes the chart from the report. The [story](/exhibit/verafin/) includes a still of the reverse.
