# WP-04: Resume outputs

## Goal
One command turns the content file into a one-page, ATS-friendly, Jake's-style resume PDF at `dist/resume.pdf` (public, never a phone number), a private copy with the phone in gitignored `out/private/`, and an Overleaf-ready `resume/resume.tex` from the same selection. The build fails loudly, naming trim candidates, if the page overflows; it never drops a bullet itself. Emeka gets before/after previews and a change log for gate G0.

## Forbidden
- Standard list (`docs/wp/_TEMPLATE.md`).
- **The phone number must never be written** into the repo, `dist/`, `resume/resume.tex`, logs, test files, the report or commit messages. The original PDF and any image rendered from it stay in gitignored `out/` only. Do not transcribe the number from the "before" image.
- Do not copy the original PDF into the repo or attach it anywhere.
- No automatic trimming: the script may only report trim candidates. Trims are content edits (`print: false`) in `resume.ts`, made by R1 deliberately and listed in `RESUME_CHANGES.md`.
- No synthesized small caps, no ligatures, no hyphenation dictionaries.
- Do not install a TeX distribution inside the repo or into `node_modules`.

## Notes
- Chromium has no Knuth-Plass line breaking or microtype, so the panel's LaTeX line estimates may not hold. Trust the gate, not the estimate.
- Ligatures and synthesized small caps garble ATS text extraction; that is why headings are uppercase with letter-spacing.
- The `computer-modern` npm package says MIT for its CSS while CMU Serif is OFL; verify the font license itself before shipping it.
- A test that needs a phone-shaped string builds it at runtime; a literal would trip `check-copy` (WP-06) and the A3 grep.
- `/resume.pdf` is public and linked from the site, so anything in it is indexed. The public PDF never has the phone; `contact.phoneInPublicPdf` is the literal `false`.
- Never auto-drop CFIA's single merged bullet: a work entry must keep at least one printed bullet.
- Unpdf extraction may join or split lines; normalize whitespace (`/\s+/g` to one space) on both sides before comparing.
