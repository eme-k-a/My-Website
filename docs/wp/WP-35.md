# WP-35: Content runbook

## Goal
Emeka's next job (or any content change) is a documented, same-day update: `docs/CONTENT_UPDATE.md` walks through every step, `npm run new:exhibit -- <id>` scaffolds a placeholder exhibit folder that passes lint and the registry test on day one, and a practice run on a scratch branch proves the whole path keeps every test green.

## Owner role
R1 Content & Resume Editor.

## Milestone and dependencies
M7. Must be merged first: WP-33. Parallel with: WP-34, WP-36.

## Inputs
- ARCHITECTURE §15.3 (adding an experience), §3 (content model, `EXHIBIT_IDS`), §6.6 (layout snapshot update), §11.2 (`npm run og`), §4 (PDF gate).
- EXPERIENCE §2.7 (what a new job does to the layout), §5.7 (placeholder crate).
- PLAN §5 WP-35 and WP-36 (dated checklist items).

## Owned globs (exclusive)
- `docs/CONTENT_UPDATE.md`, `docs/CONTENT_DRAFT.md`
- `scripts/new-exhibit.ts`, `scripts/new-exhibit.test.ts`, `scripts/templates/**`
- `src/content/**` (only on the scratch branch during the practice run; nothing from it is committed to the WP branch)
- `review/reports/WP-35.json`

## Forbidden
- Standard list (`docs/wp/_TEMPLATE.md`).
- Pushing or merging the scratch branch; committing the fake job, its id or its exhibit folder anywhere.
- Renaming or reusing an existing id.

## Commands
```sh
npm ci
npx vitest run --project unit scripts/new-exhibit.test.ts
git switch -c scratch/practice-new-job
# ... edit ids.ts and resume.ts per CONTENT_UPDATE.md, then:
npm test && npx vitest run --project unit -u src/museum/rail && npm run new:exhibit -- practice-co && npm run verify && npm run build && npm run e2e -- --project=desktop --grep @smoke
git add -A && git commit -m "chore(practice): rehearsal only, never pushed" -m "WP: WP-35"
git switch - && git branch -D scratch/practice-new-job
git status --porcelain && git branch --list 'scratch/*'
```

## Acceptance
- A1. Scaffold works. Proof: `new-exhibit.test.ts`. Threshold: pass; the scaffolded folder passes lint and the registry test.
- A2. Practice run green. Proof: the recorded command log in the report. Threshold: every step exits 0, the new stop shows the placeholder, every later main stop moved 12 m.
- A3. No residue. Proof: `git status --porcelain` and `git branch --list 'scratch/*'`. Threshold: clean; no scratch branch.
- A4. Runbook complete. Proof: `docs/CONTENT_UPDATE.md`. Threshold: the 10 steps and the dated checklist present.

## Output
- Commits: `feat(content): new-exhibit scaffold`, `docs(content): content update runbook and dated checklist`. Each ends with `WP: WP-35` and the attribution lines.
- `review/reports/WP-35.json` with the practice-run log.

## Size
S. A small script, a runbook and one rehearsal.

## Notes
- Ids are public URLs (`/exhibit/<id>/`): never rename one; append new ones.
- The layout snapshot change for a new job is expected and reviewed as a diff in its own commit.
- The PDF gate fails loudly when a new role pushes the resume past one page; trimming stays a content decision.
