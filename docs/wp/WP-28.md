## Notes
- troika cannot read woff2; the 3D subsets are woff.
- A glyph missing from a subset makes troika request a fallback font; the CSP blocks it and the e2e guard fails the run. Subset generously for the DOM (all content strings) and exactly for 3D.
- serve-dist gzips text, an upper bound on Netlify's brotli; transfer numbers from it are conservative.
