# WP-02: Freeze contracts

## Goal
Every interface that more than one role depends on exists as compiled, tested TypeScript and is tagged `contracts-v1`: the content schema and ids, the date helpers, the layout function with its pinned coordinates, the exhibit plugin types and registry, the store shape, the token names, the route table with its history transitions, the test hook and test ids, and minimal "seam" modules so M1 work packages can be built in parallel and still compile. After this WP, a change to any of these goes through R0.

R0 Orchestrator, writing with R4 Camera & Interaction (layout, routes, test hook) as the main co-author. The files land in several roles' folders by grant; each owner takes them over in later WPs.

## Milestone and dependencies

## Notes
- Date math in UTC only. `new Date('2026-10-15')` is UTC midnight; never use local-time getters.
- Sep 2026 to Dec 2026 is 4 months (inclusive count). The Experience proposal's "5 months" was wrong.
- `current` is never stored; `isCurrent(entry, now)` derives it. `tense: 'present'` after the end date fails the build from WP-03 on (`check-content`), which is how January 2027 forces the Verafin rewrite.
- `contact` is a strict object, so a phone can never be added by accident.
- Keep `import type` for schema types in client code; ESLint (WP-01) enforces it. `normalize.ts` exists so zod never ships.
- The seams are deliberately tiny. Do not grow them into features: their owners' WPs replace them, and parallel M1 branches depend on their exact export names.
- `ReadySignal` and `StatsProbe` are real now because the definition of `ready` and the shape of `stats()` are part of the test contract (ARCHITECTURE §13.4).
- `computeLayout` must never read `window` or the DOM: it runs in Node tests and in the SSR build.

- R0 ruling (2026-10-15): add `exhibit.draft: boolean` (default false) to the Presentation schema before tagging contracts-v1. It covers title, caption, tags and object text; `RELEASE=1 check:copy` (WP-06) must fail while any exhibit is draft.
