# WP-17: Slice tests

## Goal
The vertical slice is locked down: every flow built in M1 and M2 (scroll, keys, wings, dialog and history, deep links, classic and no-WebGL paths, reduced motion, quality and recovery, budgets) is covered by tagged, deterministic Playwright specs, and visual baselines exist in CI for the slice stops and dialogs. The suite passes three consecutive CI runs with `retries: 0`, which is the bar for gate G2.

## Acceptance
- A1. Local suite green. Proof: `npm run e2e && npm run a11y`. Threshold: exit 0 with `retries: 0`, twice in a row.
- A2. Coverage. Proof: `npx playwright test --list`. Threshold: every item of ARCHITECTURE §13.9 that applies to M2 has a named test (list the mapping in the report).
- A3. Baselines committed from CI. Proof: `git log --format=%s -- tests/e2e/__screenshots__ | head -1` and the file count. Threshold: commit `test(visual): baseline slice stops for WP-17`; 12 canvas baselines plus the DOM baselines listed above.
- A4. Three consecutive green CI runs with `retries: 0`. Proof: the `gh run list` command. Threshold: the last three `ci` runs on the branch all `success`, including `e2e` with `npm run visual`.
- A5. Runtime. Proof: CI `e2e` job duration. Threshold: under 10 minutes.

## Notes
- SwiftShader output varies by CPU, so baselines generated here would fail on GitHub runners; generate and compare only in CI with `@playwright/test` 1.56.1.
- `ready` covers Suspense, troika sync, `compileAsync` and two frames; `?test=1` freezes clocks and seeds noise. If a visual flakes, find the nondeterminism (file it), never raise the threshold.
- DOM screenshots mask the canvas, so dialog and classic baselines do not depend on WebGL output.
- Firefox and WebKit are not installed locally; tag DOM-only specs `@dom` now so WP-32 can run them in CI.
- Ongoing durations (Safe Sip, SDSJ) change monthly; mask `dialog-duration` and the card duration in baselines.
