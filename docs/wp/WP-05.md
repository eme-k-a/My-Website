# WP-05: Art direction

## Goal
The look of the gallery is written down once and made executable: `docs/ART_DIRECTION.md` (principles, tokens, lighting recipe per tier, material library, UI chrome, the 1-to-5 review rubric), the token values in `src/design/tokens.ts` and `src/design/tokens.css`, the font stylesheet, a material library that builds every shared three.js material from those tokens, a pass/fail concept checklist per exhibit in `review/concepts/`, and a unit test proving every text color pair meets 4.5:1.

## Owner role
R2 Art Director.

## Milestone and dependencies
M0. Must be merged first: WP-02 (token names and material names are frozen there). Parallel with: WP-03, WP-04. Feeds: WP-08 (materials for the greybox), WP-11 (lighting, tone-mapping decision), every exhibit WP (materials and checklists), WP-19 and later reviews (rubric).

## Inputs
- EXPERIENCE §1 (principles), §4 (every exhibit's checklist, materials and "reads as one object" test), §5.2 to §5.5 (plinth, case, labels, spotlights), §6.9 (age ramp), §7 (all of it: color tokens with contrast figures, classic theme, motion tokens, lighting recipe, materials library, typography, UI chrome, icons, theme rules), §10.4 (contrast and targets), §11 (delights and do-nots).
- ARCHITECTURE §7.2 (`materials: MaterialLibrary` prop), §8.1 to §8.3 (lighting, floor and glass per tier, fonts and 3D text), §8.6 (CSS vignette).
- `src/design/tokens.ts` and `src/museum/materials/index.ts` from WP-02 (names and the `MaterialLibrary` type).
- Rulings: the rubric has exactly six dimensions, D1 to D6, fixed below. Exhibits reach materials through `props.materials` or `useMaterial(name)` / `useMaterialInstance(name)`, which the kit re-exports (WP-08); exhibits never import `src/museum/materials` directly.

## Owned globs (exclusive)
- `docs/ART_DIRECTION.md`
- `src/design/**` (`tokens.ts` values, `tokens.css`, `fonts.css`, `contrast.ts`, `*.test.ts`)
- `src/museum/materials/**` (`index.ts` exports, `library.ts`, `walnutGrain.ts`, `MaterialsProvider.tsx`, `*.test.ts`)
- `review/concepts/**` (one file per exhibit id)
- `review/reports/WP-05.json`

## Forbidden
- Standard list (`docs/wp/_TEMPLATE.md`).
- Renaming, adding or removing token keys or material names frozen at `contracts-v1` (values only). A missing name goes to `openQuestions` for R0.
- New colors or materials beyond EXPERIENCE §7 without an entry in ART_DIRECTION.md explaining why (and R0 agreement for any new name).
- Transmission on any glass (`transmission` must be 0), real-time shadows, post-processing, Google Fonts or any CDN font.
- Choosing the tone mapping now: ACES Filmic, exposure 1.0 stays until the side-by-side in WP-11.

## Acceptance
- A1. Text contrast. Proof: `npx vitest run --project unit src/design`. Threshold: every text pair at least 4.5:1 and focus rings at least 3:1; test passes.
- A2. Material library. Proof: `npx vitest run --project unit src/museum/materials`. Threshold: passes; exactly eight exhibit-allowed names; zero transmission.
- A3. Names frozen. Proof: `tokens.test.ts` (key-path snapshot from WP-02) passes unchanged, and the materials name arrays are unchanged versus `contracts-v1`. Threshold: pass; the `git diff` shows value changes only.
- A4. Rubric. Proof: `grep -cE '^\| D[1-6] ' docs/ART_DIRECTION.md`. Threshold: `6`, and D6 is the 320 px grayscale thumbnail test.
- A5. Ten concept checklists. Proof: the `for id` loop. Threshold: every file exists with at least 6 unchecked items.
- A6. Build and verify. Proof: `npm run verify && npm run build`. Threshold: exit 0 (fonts resolve from `node_modules`, no external URLs in `dist/assets/*.css`: `grep -l 'https://' dist/assets/*.css` prints nothing).

## Notes
- troika cannot read `.woff2`; the 3D labels use the `.woff` files from the same `@fontsource` packages (WP-08 imports them by URL). The DOM uses woff2 through `fonts.css`.
- Google Fonts, unpkg and jsDelivr are unusable (CSP is self-only; unpkg is blocked here). Everything comes from npm.
- Keep `--text-3` (3.7:1) decorative only; the test enforces it.
- The 320 px grayscale thumbnail test exists because ten code-built objects from four builders drift toward "programmer art" (busy clusters). The checklists' "reads as one object" line is the first box for every exhibit.
- Verafin checklist must keep the copy guard: no red or amber bars, no flagged bar, no detection imagery.
- Contact shadows are rendered once and baked; tone mapping (ACES or AgX) is decided from side-by-side screenshots in WP-11 and then frozen as `render.toneMapping`.
