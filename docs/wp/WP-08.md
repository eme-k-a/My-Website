# WP-08: Greybox + kit

## Goal
The 3D stage exists: a fixed canvas behind the DOM, a greybox hall built entirely from `computeLayout()` (lobby, aisle, both wing rooms, Foundations, desk zone), instanced plinths and glass cases in all three slot variants, and the exhibit kit (`ExhibitFrame` with Suspense, error boundary, distance mounting, compile-before-reveal, hit box and 3D placard labels; `Placeholder`; clock, noise and texture helpers). Every slot shows the placeholder crate, so every stop works from day one, within 80 draw calls.

- drei `<Html>`, `ScrollControls`, or any wheel or touch handler; `touch-action: none`.
- Editing rail, store, test hook, quality or overlay files (use their exports; request changes in `openQuestions`).
- Hand-typed coordinates: every position comes from `computeLayout(content, buildDate)` or from kit-local offsets relative to a slot.

## Notes
- With sections layered over a fixed canvas, pointer events never reach R3F unless `eventSource` is the app root (`#app`) and sections are `pointer-events: none` (WP-09 does the CSS). Every case also has a DOM "Read the story" button, so 3D clicks are a convenience, not the only path.
- Mounting an exhibit compiles new shader programs; doing it at arrival stalls phones for 100 to 400 ms. Mount hidden two stops ahead, `compileAsync`, then reveal. WP-16 verifies the program count stays flat after arrival.
- `frameloop="demand"` is permanent; the interim `FrameDriver` (WP-02 seam) invalidates every frame until WP-16 makes it smart.
- Use `100lvh` and ignore height-only resizes under 20% on touch devices: the iOS address bar would otherwise resize the drawing buffer while scrolling.
- Contact shadows render once (`frames={1}`); no shadow maps anywhere.
- Troika text appears asynchronously; `ready` must wait for `onSync` of every mounted label, or screenshots flake.
- Exhibit meshes are never raycast; only the frame's box is. This keeps hover cheap and deterministic.
- R0 ruling (2026-10-15): when the kit tints instanced beam cones per target with `instanceColor`, set the beam material color to white. three multiplies `instanceColor` by `material.color`, so leaving it at light-0 would tint the cones twice.
