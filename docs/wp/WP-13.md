# WP-13: Safe Sip exhibit

## Goal
Exhibit No. V1, "Tamper Evident", replaces the placeholder in the Volunteer wing: a frosted cup with a cut-away, layer-stepped lid showing a Raspberry Pi Pico W board and an orientation sensor, rocking gently in a brass gimbal, with the tamper ring lighting only when the tilt passes the threshold. Built by a different builder from Verafin, under the same rules, so gate G2 can judge whether two builders produce one consistent collection.

## Notes
- The stepped lid is real geometry (a Lathe profile with 3 mm steps), not a shader; stepped profiles add triangles, so keep segments at 48 and watch the estimate (about 6,500).
- `phiLength` 270° leaves open faces; close them only if the cut reads poorly, and stay under budget.
- The tamper ring is a consequence of the rocking, driven by the same clock. A separate pulse or timer would be a second motion.
- The exhibit sits in the Volunteer wing (door after Mysa); `goTo('safe-sip')` enters the wing through the real path (with its history entry, ARCHITECTURE §6.7). Test from there, not by scrolling.
- Use `useMaterialInstance` for the ring's emissive so the shared `accentGlow` program is reused.
